# 치이카와 키우기

키보드·마우스로 활동한 시간이 에너지가 되어 친구의 집을 키우는 macOS 메뉴 막대 팬 앱입니다.

### 설치는 3단계

1. 다운로드한 **ChiiBar-macOS.zip**을 더블클릭해 압축을 풉니다.
2. **ChiiBar.app**을 **응용 프로그램** 폴더로 옮깁니다.
3. 앱을 열고 **화면 맨 위 메뉴 막대의 캐릭터 아이콘**을 누릅니다. 첫 친구를 만나면 준비 끝!

> **처음 실행할 때 보안 안내가 뜨나요?** 아직 Apple 공증을 받지 않은 팬 앱입니다. 다운로드 출처를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 실행할 수 있습니다. [Apple의 실행 안내](https://support.apple.com/ko-kr/102445)

**업데이트:** 실행 중인 치이바를 메뉴 막대 우클릭 → **종료**한 뒤 새 앱으로 교체하세요. 친구·집·뽑기권은 유지됩니다.

## 이렇게 키워요

**평소처럼 작업하기 → 활동 경험치 쌓기 → 집 업그레이드 → 새 친구 만나기**

- 시작 버튼 없이 활동을 자동으로 기록합니다. 하루 목표는 **4시간**입니다.
- **활동 1시간마다 뽑기권 1장**을 받아 새 친구를 만납니다. 모인 표는 한 번에 뽑을 수도 있어요.
- **산책가자!**를 누르면 친구가 바탕화면을 걸으며 쉬고, 구르고, 반응합니다.
- 로컬 AI를 쓰면 성장에 작은 **Extra 경험치**가 더해집니다.

## 자동 활동 기록

- 키보드 입력·마우스 클릭·스크롤 뒤 **5분까지** 활동으로 인정합니다. 마우스 이동만으로는 연장하지 않습니다.
- 활동이 겹치면 한 번만 계산합니다. 10:00 입력 뒤 10:04에 다시 입력하면 10:09까지 총 9분입니다.
- 화면 잠금·잠자기·다른 사용자로 전환한 동안에는 멈춥니다. 앱이 꺼져 있던 시간은 소급 적립하지 않습니다.
- 다시 입력하면 자동으로 이어집니다. 매번 시작 버튼을 누르지 않아도 됩니다.
- **하루 목표는 활동 4시간**입니다. 목표를 넘어도 에너지는 계속 쌓입니다.
- Extra XP: 환산 토큰 100개당 1 XP, 활동 경험치의 최대 5%이자 하루 최대 12,000 XP(활동 6분 분량). 집 성장에만 더하고 활동 시간·뽑기권에는 더하지 않습니다. 기능을 처음 켠 이후의 당일 사용량만 인정합니다.
- 활동 1분은 에너지 2,000입니다. 뽑기권은 에너지 12만(활동 1시간)마다 한 장입니다.
- 오늘의 활동 시간과 날짜별 누적 합계를 Mac 안에 저장합니다.

## 집 업그레이드

하루 활동 6시간을 기준으로 첫날 약 3번, 다음 날 약 2번 이사할 수 있게 맞췄습니다. 현재 친구의 집 하나를 키우는 기준이며 중복 친구 선물과 기존에 모은 에너지는 별도입니다. 에너지가 모이면 직접 업그레이드합니다.

| 새 집 | 필요한 활동 시간 |
|---|---:|
| 움막집 | 1시간 |
| 벽돌집 | 1시간 30분 |
| 굴뚝집 | 2시간 |
| 울타리집 | 2시간 30분 |
| 마당집 | 3시간 30분 |
| 초가집 | 5시간 |
| 양반집 | 7시간 |
| 현대식집 | 9시간 |
| 빌라 | 12시간 |
| 아파트 | 15시간 |
| 초고층 빌딩 | 19시간 |
| 펜트하우스 | 24시간 · 하루 6시간 기준 약 4영업일 |

기존 친구·집 단계·뽑기권은 유지하고, 집의 진행률과 초과 에너지는 새 기준의 같은 비율로 옮깁니다. 처음 옮길 때 저장 원본의 백업을 남깁니다. 중복 친구는 다음 집 비용의 10%, 최대 활동 15분에 해당하는 에너지를 줍니다. 완성한 집의 친구가 중복되면 표를 돌려줍니다.

## 친구와 산책

- **뽑기**에서 하나씩·한 번에 모두 뽑기를 선택합니다. 단체는 실루엣·빛 연출 뒤 바로 전체 결과 목록을 보여줍니다.
- **산책가자!**를 누르면 캐릭터·일본어 이름·말풍선이 화면을 산책합니다. 클릭하면 반응하고 우클릭 → **산책 끝내기**로 돌아옵니다.
- 양반집은 갓, 아파트·초고층 빌딩·펜트하우스는 나비넥타이입니다. 다른 집은 기본 모습입니다.
- 대사에는 가끔 캐릭터별 일본어도 나옵니다. 대사와 액세서리는 팬 창작입니다.

## 데이터와 개인정보

키보드·마우스의 **마지막 활동 후 경과 시간**만 macOS에 묻습니다. 입력한 글·누른 키·마우스 좌표·클릭한 내용은 읽거나 기록하지 않습니다. 날짜별 활동 시간과 게임 진행만 로컬에 저장하며 서버로 전송하지 않습니다. Extra XP를 위해 기본 실행은 Claude Code·Codex의 로컬 JSONL 로그에서 사용량 숫자를 읽습니다. 대화 본문을 저장하거나 전송하지 않습니다. 활동 통계는 저장된 활동 합계만 읽습니다. 예전 저장 파일의 토큰 기록은 호환을 위해 보존합니다.

활동 감지가 불가능하면 앱의 **감지 권한 확인**을 이용합니다. 앱 자체에는 아직 로그인 시 자동 실행·자동 업데이트가 없습니다. 움직임 줄이기를 켜면 산책과 연출 모션이 줄어듭니다.

## 팬 프로젝트

비공식·비상업 팬 앱이며 원작 권리자와 관계가 없습니다. 캐릭터의 권리는 원 권리자에게 있습니다.
